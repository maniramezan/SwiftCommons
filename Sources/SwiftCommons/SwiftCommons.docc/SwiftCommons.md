# ``SwiftCommons``

Shared Swift utilities and helpers for reusable app code.

## Overview

SwiftCommons provides lightweight extensions and helpers around Foundation, dates, locales, and logging. The package is dependency-free and focuses on small, composable utilities.

### Foundation Extensions

- ``Array``
- ``Optional``
- ``URL``
- ``Locale``
- ``FixedWidthInteger``
